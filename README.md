# PZWKeys

Simple WoW 7.3.5 M+ keystone helper. Adds minor QoL features that I found missing.

## Features

* **Add `-keys` command that makes every other user of this addon link their keystone into the party/guild chat.**
* **Autoinsert the keystone into the keystone slot when starting the dungeon.**
* **Adds `Readycheck` and `Pull 10` next to activate button on the keystone window.**

![Readycheck and pull10 buttons image](https://i.imgur.com/PHYHnKv.png)
